# StudySphere

A student study and productivity web app built with HTML5, CSS3 and vanilla JavaScript. No backend or frameworks.

## Features
- Dashboard with live stats and overall progress bar
- Task manager (subject, priority, due date, filters)
- Pomodoro study timer (25/5) with session tracking
- Weekly timetable
- Notes (create, edit, delete, search)
- Subject progress tracking
- Goal tracking
- Global search across tasks, notes and goals
- Dark/light mode
- Fully responsive

All data is saved in your browser's `localStorage`.

## Run it
Open `index.html` in a browser, or use VS Code with the Live Server extension (right-click `index.html` → Open with Live Server).

## Files
- `index.html` – structure
- `style.css` – styling and responsive layout
- `script.js` – all app logic
